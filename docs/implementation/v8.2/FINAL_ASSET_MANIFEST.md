## 7. Deterministic Fallback Hierarchy

All resolvers inside `src/lib/config/media-manifest.ts` obey a deterministic three-tier fallback chain:
1. **Specific offering / book slug match** (`resolveCourseThumbnailAsset(cat, offering)` / `resolveBookCoverAsset(slug, cat)`).
2. **Category / track level match** (`COURSE_CATEGORY_MEDIA[categorySlug]` / `BOOK_CATEGORY_TO_DEFAULT_SLUG[categorySlug]`).
3. **Guaranteed local pillar default** (`DEFAULT_COURSE_MEDIA` / `DEFAULT_BOOK_COVER_MEDIA`), verified on disk by `tests/unit/v82-media-manifest.test.ts` so zero runtime external requests or broken images occur.
