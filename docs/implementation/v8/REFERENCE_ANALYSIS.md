## 1. Visual & Structural Audit of Client References

### A. Layout & Component Proportions (Bunyanum Marsus)
1. **Top Utility Strip & Single-Row Header:** Slim dark top bar with contact/WhatsApp strip above a clean white sticky header (`h-20`, `1px` subtle bottom border `#E1E4F2`), left logo + brand title, center single-row links, right compact utility buttons.
2. **Hero Slideshow + Segmented `01 — 04` Indicator (`Screenshot 2026-11-26 231335`):**
   - Compact full-width promotional hero banner avoiding bloated multi-screen height.
   - Centered rounded segmented progress pill directly beneath the banner: `01 — 04`, 4 horizontal progress bars, prev/pause/next controls.
   - Centered hairline divider with uppercase brand tagline: `ONE PARTNER · COMPLETE SOLUTIONS · CONFIDENT GROWTH`.
3. **Gateway Buttons Directly Below Divider:** Clean centered multi-column gateway buttons (`Courses → Services → Books`) sharing identical visual fill and icon structure.
4. **Popular Courses Grid (`Screenshot 2026-11-26 231321`):**
   - Centered heading (`আমাদের জনপ্রিয় কোর্সসমূহ`) + short accent bar + centered 1–2 line subtitle.
   - Centered category filter button row (`সব` active blue button + light category filter buttons).
   - Clean 4-column desktop grid (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`): white card (`rounded-[16px]`, subtle border), 16:9 visual top banner, Bengali course title, hairline divider, bottom price/status left + compact `বিস্তারিত >` pill-free button right.
5. **Services Gateway Frame (`Screenshot 2026-11-26 231239 (1)`):**
   - Rounded outer section frame (`rounded-[24px]`) with centered badge + dual-tone heading (`আমাদের পেশাদার সেবাসমূহ`) + diamond hairline divider + subtitle + interactive track selector tabs.
   - Inner split panel: Left track icon + checklist bullets + `বিস্তারিত দেখুন →` + WhatsApp CTA + privacy note; Right white elevated form card with `#F5F6FA` soft inputs and full-width `#243FBA` primary CTA.
6. **Institutional Profile 2-Column Section (`Screenshot 2026-11-26 231321`):**
   - Dark Midnight Navy (`#081838`) rounded container.
   - Left column: Framed badge card with official circular BCP logo (`public/brand/bcp-master-logo.png`), tagline, and `/about` link (honestly presenting BCP institutional identity rather than fabricating an unverified personal mentor).
   - Right column: Section heading + numbered vertical timeline list (`১` to `৪`) with gold numbered circles (`#C59028`/`#DFB15B`) and connecting vertical rule.
7. **Dedicated E-Commerce Books Section (`#pillar-books`):**
   - Centered header + category filter tabs + 4-column hardcover `aspect-[3/4]` e-commerce product cards with honest `প্রকাশনা আসন্ন` status (or verified BDT price when published) and `বিস্তারিত`/`অর্ডার করুন` CTA.
8. **Contact Page (`Screenshot 2026-11-26 231359`):**
   - Centered header (`আমাদের সাথে যোগাযোগ করুন`) + subtitle over soft periwinkle header band.
   - Two-column desktop split: Left `যোগাযোগের তথ্য` cards + `#202D72` rounded quick-connect box (`সরাসরি ও দ্রুত যুক্ত থাকুন`); Right white elevated `ConsultancyForm` card with `#F5F6FA` inputs.

### B. Palette Transfer (AKIJ iBOS Managerium)
- Adopted the white-dominant light mode canvas (`#FFFFFF`) accented with `#B3B6FF` / `#B8BBFF` radial corner blooms, `#E2E3FF` periwinkle light button/card fills, `#F5F6FA` subtle input surfaces, `#243FBA` functional blue buttons, and `#202D72` deep blue headings—strictly excluding ERP modules or dashboard screenshots.
